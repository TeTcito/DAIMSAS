# DAIM S.A.S. - Ingeniería, Montajes y Mantenimiento Industrial

Sitio web corporativo y landing page de alta fidelidad para **DAIM S.A.S.**, empresa especializada en montajes industriales, ingeniería eléctrica, automatización, piping, energía solar y obras civiles.

🌐 **Sitio Web en Vivo (Firebase Hosting):** [https://daimsas.web.app](https://daimsas.web.app)

---

## 🚀 Tecnologías Utilizadas

- **Frontend:** React 18
- **Bundler / Tooling:** Vite 5
- **Estilos:** Tailwind CSS con paleta de color personalizada:
  - Azul Marino Profundo: `#0B1E33`
  - Naranja Corporativo: `#F26522`
  - Azul Eléctrico: `#0284C7`
- **Iconografía:** Lucide React
- **Hosting:** Google Firebase Hosting

---

## 🛠️ Instalación y Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/TeTcito/DAIMSAS.git
cd DAIMSAS

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

---

## 📦 Despliegue en Firebase

```bash
# Compilar proyecto
npm run build

# Desplegar a Firebase Hosting
firebase deploy --only hosting
```
